# 学习路线图

从零基础到「能放心写多线程」，共 19 课。顺序是刻意排过的：每一课都踩在上一课的知识上。

## 第一阶段：程序是个什么东西（第 0 课）

| 课 | 主题 | 解决的困惑 |
|---|---|---|
| [00](00-程序是怎么跑起来的.md) | 程序是怎么跑起来的 | 我写的代码，电脑为什么不认识 |

## 第二阶段：Java 的地基（第 1 ~ 5 课）

| 课 | 主题 | 解决的困惑 |
|---|---|---|
| 01 | 变量与类型 | 变量到底是个什么；为什么 `7/2` 是 3 |
| 02 | 运算符与流程控制 | `&&` 为什么会"短路"；`switch` 怎么写得不用心慌 |
| 03 | 方法 | 为什么要抽方法；为什么传进去改不了外面的变量 |
| 04 | 类与对象 | 类是说明书、对象是实物；`static` 到底属于谁 |
| 05 | 继承与多态 | 同一个调用，为什么不同对象结果不一样 |

## 第三阶段：写起来更省力的工具（第 6 ~ 10 课）

| 课 | 主题 | 解决的困惑 |
|---|---|---|
| 06 | 泛型 | 一个类处理所有类型，不用为 String 再抄一份 |
| 07 | Lambda | 不用为了发一条消息特意建一个类 |
| 08 | Optional | 让 `null` 在类型上就看出来，而不是运行时才炸 |
| 09 | 反射 | 运行时才知道类名，怎么创建对象、调方法 |
| 10 | Stream | 用声明式取代 for 循环 |

## 第四阶段：多线程（第 11 ~ 18 课）

| 课 | 主题 | 解决的困惑 |
|---|---|---|
| 11 | 并行流 | 第一次写多线程：为什么结果是乱序的 |
| 12 | 多线程基础 | 线程创建、生命周期、守护线程、中断 |
| 13 | 线程安全与同步 | 为什么加了锁就对了 |
| 14 | JMM 与 volatile | 为什么改了值对方看不见 |
| 15 | 锁 | synchronized 细节、ReentrantLock、死锁 |
| 16 | 线程通信 | 两个线程怎么互相配合 |
| 17 | 线程池 | 别随用随建线程；7 个参数怎么填 |
| 18 | 并发集合与 ThreadLocal | ConcurrentHashMap、内存泄漏 |

## 每一课的写法

```markdown
## 一、先让代码疼一次     ← 笨办法先跑通，挑出毛病
## 二、正解               ← 可运行的完整代码块 + 真实输出
## 三、等价写法与边界     ← 最值钱的部分
## 四、不推荐的用法
## 五、术语表 + 下期再见
```
